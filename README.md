## Results

The activation functions and optimization algorithms were compared using training accuracy, validation accuracy, training loss, validation loss and convergence behavior.

The actual experimental results are available in `optimizer_results.csv`.

## Conclusion

The experiment demonstrates that the choice of activation function and optimization algorithm affects neural network training speed, convergence and generalization performance. ReLU generally provides efficient training, while adaptive optimizers such as Adam often provide fast convergence.
